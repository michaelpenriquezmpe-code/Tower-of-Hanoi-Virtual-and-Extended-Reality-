# Tower of Hanoi in WebXR

An interactive Extended Reality (XR) implementation of the classic Tower of Hanoi puzzle, built for the web using WebXR technologies. Users can visualize and manipulate disks in a 3D immersive environment directly in a browser or XR headset.

## 🎯 Project Overview

This project recreates the Tower of Hanoi puzzle in an immersive XR environment. It allows users to interact with disks and rods in 3D space, demonstrating recursive problem-solving concepts through spatial interaction and visualization.

The application runs in modern browsers with WebXR support and can be experienced on desktop (mouse/keyboard) or XR devices (VR/AR headsets).

## 🚀 Features

- Interactive 3D Tower of Hanoi puzzle
- WebXR immersive mode support
- Drag-and-drop disk interaction
- Real-time visual feedback
- Educational visualization of recursion
- Cross-platform browser compatibility

## 🛠️ Technologies Used

- HTML5
- JavaScript
- WebXR API
- Three.js / WebXR libraries (if applicable)
- WebGL
